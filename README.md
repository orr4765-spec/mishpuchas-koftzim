# משפוחס קופצים 🦘

משחק מובייל משפחתי: מחזיקים את האצבע כדי למתוח חבל, משחררים – והוא נהיה גשר לעמוד הבא.
נחיתה בדיוק על הנקודה האדומה = **מושלם!** ובונוס קומבו.

- 3 טבלאות מובילים: היום / השבוע / כל הזמנים (Firebase – ראו `FIREBASE-SETUP.md`)
- חנות: דמויות, חבלים, שבילים, עולמות, אימוג׳י – בדרגות רגיל / נדיר / אפי / אגדי / **מיתי**
- פריטים אגדיים מופיעים רק בחנות היומית; פריטים מיתיים לא נמכרים – רק נפתחים מהישגים
- בוסטים כלכליים בלבד (מטבעות x2, XP x2, קסם מזל, תיבת הפתעה) – בלי יתרון במשחק עצמו

## הרצה מקומית

```
npm install
npm run dev
```

כל דחיפה ל-`main` מעלה את המשחק אוטומטית ל-GitHub Pages.
